## About

- 관공서 디지털 서포터즈로 3개월간 어르신들의 키오스크 사용을 도우며, **동작하는 UI와 실제로 쓸 수 있는 UI는 다르다**는 걸 배웠습니다.
- 그래서 코드가 돌아가는지보다 **왜 이렇게 동작하는지**, 사용자는 어떻게 쓰게 되는지를 먼저 확인합니다.
- 프로젝트 3개를 리팩토링하며 트러블슈팅 **9건**을 정리했고, 그중 **6건**은 실제 버그였습니다.
